# Pac-Ma'am / Keeping the chaos organised

**Rasmus + Ilias | started 3 October 2026 | 42 Berlin, Rank 4**

Two people, one Pac-Man game, a frankly unreasonable amount of pink. We keep things simple: talk about what needs doing, split the work, put the important decisions somewhere we can find them, and don't merge broken code.

This folder is our project notebook, not a management consultancy. The weekly notes are short on purpose. If something needs a paragraph to explain, it probably belongs in the technical README instead.

| File | What's in it |

| `02_WORKING_RULES.md` | How we avoid stepping on each other's code (and other hazards) |
| `03_WEEKLY_NOTES.md` | Weekly check-ins from 3 October onward |
| `04_TASK_BOARD.md` | What's done, underway and still to check |
| `05_DECISIONS.md` | Decisions worth remembering |
| `06_CHANGELOG.md` | Big changes, without pretending every commit needs a novel |
| `07_REQUIREMENTS.md` | Subject checklist and what we must still demonstrate |
| `08_RELEASE_CHECKLIST.md` | Final sanity check before handing it over |

## The rhythm

A short weekly conversation, plus messages when something actually changes. If one of us gets stuck, we say so. We don't hold a meeting to schedule the meeting where we'll discuss the bug.

**Important:** This isn't a replacement for the Git history or the actual 42 subject. The checklists are there to help us verify the final merged build, not to claim every box has already been ticked.
